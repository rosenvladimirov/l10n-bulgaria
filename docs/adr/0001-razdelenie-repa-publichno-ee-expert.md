# ADR-L-0001: Разделение на репозиториите — публично / EE / expert

- **Статус:** приет (лицензната картина по модул е [PLACEHOLDER-KOSTOV])
- **Дата на решението:** ок. 2026-05…07 (оформено; действащо)
- **Дата на записа:** 2026-07-13 (консолидация)
- **Взето от:** Росен Владимиров
- **Източник на реконструкцията:** memory `topics/licensing/licensing_master_reference` §6, `topics/licensing/module_tiers_2026_07_11`, `topics/licensing/project_license_hygiene_2026_07_11`

## Контекст

Българската локализация обхваща 190+ модула с различна търговска стойност и лицензен режим. Публичното (OCA/общност) и комерсиалното (проприетарни надстройки) не могат да живеят под един лиценз в едно репо, защото AGPL заразява надолу по `depends` веригата.

## Разгледани алтернативи

1. **Едно репо, смесени лицензи.** — Отхвърлено: AGPL/OPL-1 в едно репо → транзитивно заразяване, невъзможен одит.
2. **Форк per клиент.** — Отхвърлено принципно ([[feedback_no_private_forks_client_repos]]).
3. **Три репа по режим: публично AGPL / частно EE OPL-1 / частно expert OPL-1.** — Прието.

## Решение

- **`rosenvladimirov/l10n-bulgaria`** (публично) — root `LICENSE` = AGPL-3; отделни модули явно LGPL-3 където са предназначени за OPL-1 надстройки.
- **`l10n-bulgaria-ee`** (частно) — режим OPL-1: ДДС отчети/декларации, ведомости/ТРЗ.
- **`l10n-bulgaria-expert`** (частно) — режим OPL-1: ДДС протоколи, митници (DN+MRN), AI pipeline.

Границата на репата = границата на лицензната архитектура. Частните репа са под CLA gate ([ADR-L-0003](0003-cla-gate.md)).

## Обосновка

Разделянето по репо материализира лицензната граница и позволява одит на `depends` затварянето (нито OPL-1/LGPL модул да не стъпва транзитивно на AGPL). Публичното остава публично; комерсиалната стойност е изолирана в частните репа.

## Последици

- Модул, който мигрира между режими, мигрира между репа (license hygiene, 13.07: city→LGPL, 18 модула fork→expert).
- Веригите `depends` се одитират за AGPL заразяване (licensing_master_reference §1).
- Финалната лицензна карта по модул = [PLACEHOLDER-KOSTOV] (нанася се при одита с адв. Костов).
