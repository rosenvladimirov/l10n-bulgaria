Configuration
============

To use this module, you need to:

* Go to Settings
* Enable address management features
* No other configuration is needed

Usage
=====

To use this module, you need to:

#. Go to Contacts or Companies
#. Create or edit an address
#. Fill in the detailed address fields:
    * Street Name
    * House Number
    * Building Number
    * Floor Number
    * Sector Number
    * Door/Apartment Number

The module will automatically format the address according to Bulgarian standards.
