This module extends the standard Odoo asset management to comply with Bulgarian tax law requirements for depreciation calculation and reporting.

**Table of contents**

.. contents::
   :local:

Features
========

* **Tax Depreciation Board**: Generate depreciation schedules according to Bulgarian tax law
* **Percentage-based Depreciation**: Calculate depreciation using percentage rates instead of periods
* **Freeze Periods**: Support for pausing depreciation during specific periods
* **Tax Models**: Create reusable depreciation templates
* **Disposal Date Tracking**: Track asset disposal dates for tax purposes
* **Comprehensive Reports**: Generate tax-compliant depreciation reports

Configuration
=============

Company Settings
----------------

1. Navigate to **Accounting → Configuration → Settings**
2. Ensure your company has the correct fiscal year configuration

Asset Configuration
-------------------

1. Go to **Accounting → Configuration → Assets Models**
2. Create or edit an asset model
3. Set the **Percentage Depreciation** field (e.g., 20 for 20% annual depreciation)
4. Optionally, mark the model as a **Tax Model** for reuse

Tax Model Setup
---------------

1. Create a new asset and mark it as **Is Tax Model**
2. Configure the depreciation percentage
3. Use this model as a template by selecting it in the **Tax Model** field of other assets

Usage
=====

Creating Assets with Bulgarian Tax Depreciation
------------------------------------------------

1. Navigate to **Accounting → Assets**
2. Create a new asset or edit an existing one
3. Fill in the required fields:

   * **Asset Name**
   * **Original Value**
   * **Acquisition Date**
   * **First Depreciation Date**

4. Set the **Percentage Depreciation** (e.g., 20 for 20%)
5. Optionally select a **Tax Model** to inherit settings
6. Save the asset

The module will automatically:

* Calculate the depreciation schedule based on the percentage
* Generate tax depreciation board entries
* Calculate the number of years and months for full depreciation
* Handle prorata calculations for mid-year acquisitions

Viewing Tax Depreciation Board
-------------------------------

1. Open an asset
2. Click on the **Tax Depreciation** smart button
3. View the complete depreciation schedule according to Bulgarian tax law

Each line shows:

* **Sequence**: Order number
* **Period Date**: End date of the period
* **Original Value**: Initial asset value
* **Depreciation Value**: Amount depreciated in the period
* **Value Residual**: Remaining value after depreciation
* **Method Percentage**: Applied depreciation rate

Freeze Periods
--------------

If you need to pause depreciation for certain periods:

1. Open an asset
2. Set the **Paused Prorata Date**
3. The system will automatically adjust the depreciation schedule
4. View freeze periods in the **Freeze Periods** tab

Generating Reports
------------------

1. Go to **Accounting → Reporting → Bulgarian Asset Report**
2. Select the reporting period
3. Filter by asset category, account, or other criteria
4. Export to PDF or Excel

The report includes:

* Asset characteristics (acquisition date, method, rate)
* Opening and closing asset values
* Additions and disposals
* Opening and closing depreciation
* Current period depreciation
* Net book value

Technical Details
=================

Depreciation Calculation
------------------------

The module uses the following formula for percentage-based depreciation:

* **Monthly Depreciation** = (Residual Value × Percentage) / 12
* **Total Months** = (1 / Percentage) × 12
* **Years** = Total Months / 12

Example: For 20% depreciation:

* Monthly rate = 20% / 12 = 1.67%
* Total depreciation period = 60 months = 5 years

Models
------

**bg.account.asset.depreciation.board**
  Stores the tax depreciation schedule for each asset

**bg.account.asset.freeze.periods**
  Tracks periods when depreciation is paused

Fields Added to account.asset
------------------------------

* ``l10n_bg_depreciation_ids``: One2many to depreciation board
* ``l10n_bg_freeze_period_ids``: One2many to freeze periods
* ``l10n_bg_method_percentage``: Depreciation percentage (0-100)
* ``l10n_bg_tax_model_id``: Link to tax model template
* ``l10n_bg_tax_model``: Boolean flag for tax models
* ``l10n_bg_disposal_date``: Asset disposal date for tax purposes
* ``paused_prorata_date``: Date when depreciation was paused
