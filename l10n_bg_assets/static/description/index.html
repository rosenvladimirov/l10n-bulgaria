Bulgarian Asset Management

Tax depreciation calculation and reporting compliant with Bulgarian law

Price: €150 License: OPL-1

This module extends the standard Odoo asset management to calculate depreciation according to Bulgarian tax law. It supports percentage-based depreciation, freeze periods, tax models, and generates comprehensive reports for tax compliance.

Key Features

Percentage-Based Depreciation

Calculate depreciation using percentage rates (e.g., 20%) instead of fixed periods

Tax Depreciation Board

Generate detailed depreciation schedules compliant with Bulgarian tax law

Freeze Periods

Support for pausing depreciation during specific periods

Tax Models

Create reusable depreciation templates for consistency across assets

Automatic Calculations

Automatic calculation of monthly depreciation, residual value, and total periods

Comprehensive Reports

Generate tax-compliant reports with opening/closing balances and movements

Disposal Tracking

Track asset disposal dates and adjust depreciation accordingly

Configuration Process

Step 1

Configure company fiscal year settings in Accounting → Configuration → Settings

Step 2

Create asset models with depreciation percentages in Assets → Configuration → Models

Step 3

Optionally create tax model templates for reuse across similar assets

Step 4

Create assets and assign depreciation percentages or tax models

How to Use

  1. Navigate to Accounting → Assets
  2. Create a new asset or edit an existing one
  3. Set the Percentage Depreciation (e.g., 20 for 20% annual depreciation)
  4. Optionally select a Tax Model to inherit settings
  5. Save the asset - the system automatically generates the depreciation board
  6. Click the Tax Depreciation smart button to view the schedule
  7. Generate reports via Accounting → Reporting → Bulgarian Asset Report

Depreciation Calculation Example

Understanding how percentage-based depreciation works

Example: 20% Annual Depreciation

Asset Value: 10,000 BGN
Annual Rate: 20%
Monthly Rate: 20% ÷ 12 = 1.67%
Total Period: 60 months (5 years)
Monthly Depreciation: 10,000 × 1.67% = 166.67 BGN
