🌟 **Cerberus: Guardian of Digital Secrets**
============================================

The **Cerberus** module represents a cryptographic virtual wallet for storing
the most sensitive data in Odoo systems. Inspired by the mythical hound guardian
of Hades' realm, this module provides impenetrable protection for:

* 🔐 **RSA Keys** - for cryptographic operations
* 🗝️ **API Keys** - for bank and external system integrations
* 🛡️ **Passwords** - for system access
* 📜 **Certificates** - for digital signing
* 💎 **Other Precious Secrets** - everything that must remain hidden

🏛️ **Architecture of the Underworld**
=====================================

Cerberus uses the most modern cryptographic techniques, worthy of Hades' guardian:

**🔮 The Ritual of Transformation (PBKDF2HMAC)**
------------------------------------------------
Like ancient rituals for passage to the afterlife, every password undergoes
**100,000 iterations** with **SHA256**, transforming it into an impenetrable key.

**⚡ The Magical Barrier (Fernet)**
----------------------------------
Symmetric encryption with **Fernet** creates an impermeable barrier around data,
accessible only to the holder of the correct password.

**🧂 The Salt of Oblivion (Salt)**
---------------------------------
Each wallet has a unique salt stored separately - like the river waters
of Styx that guard the boundaries between worlds.

🎭 **Guardian's Functionality**
==============================

**🚪 Unlocking the Portal**
---------------------------
Cerberus recognizes its master and unlocks the wallet only with the correct password:

.. code-block:: python

    # Unlock with user password
    wallet = self.env['crypto.wallet'].get_user_wallet()
    success = wallet.unlock_with_user_password()

    # Unlock with master password
    success = wallet.unlock_wallet(master_password)

**🗝️ Key Management**
--------------------
Adding, retrieving, and removing secrets from the wallet:

.. code-block:: python

    # Adding an API key
    wallet.add_key_with_user_password(
        key_name="bank_api_key",
        key_type="api_key",
        key_data="sk_live_51ABC..."
    )

    # Retrieving an RSA key
    private_key = wallet.get_key_with_user_password("rsa_private_key")

    # List all keys
    keys = wallet.list_keys_with_user_password()

**⚗️ Quick Access**
------------------
For daily operations without unlocking:

.. code-block:: python

    # Quick storage
    wallet.quick_store("temp_token", "xyz123")

    # Quick access
    token = wallet.quick_access("temp_token")

**📤 Export to the Beyond**
--------------------------
Transferring wallets between different systems:

.. code-block:: python

    # Export with password
    export_data = wallet.export_wallet(
        master_password=password,
        export_encrypted=True,
        export_password="backup_password"
    )

🚀 **Installation**
==================

**📋 Prerequisites**
-------------------
The module requires the Python `cryptography` library:

.. code-block:: bash

    pip install cryptography

**⚙️ Configuration**
-------------------
1. Install the module from the Apps menu
2. Go to **Settings → Users** and set passwords
3. Navigate to **Crypto Wallets → Wallets**
4. Create your first wallet

**🔧 Automatic Wallet**
----------------------
The system automatically creates a "System Keys" wallet for each user on first use.

🔍 **Known Limitations**
=======================

* **Forgotten password = lost data** - no recovery without master password
* **User password dependency** - changes require re-encryption
* **Performance** - 100K iterations may slow operations
* **Data size** - recommended up to 64KB per key

⚠️ **Important Warnings**
=========================

.. warning::
   **NEVER lose the master password!**
   Cerberus does not forgive - a lost password means permanently vanished secrets.

.. danger::
   **Do not share master passwords!**
   Anyone with password access can unlock the wallet.

🐛 **Known Issues**
==================

* When changing user password, wallets require manual re-encryption
* Export is one-way - no automatic import wizard
* Browser may temporarily cache decrypted data
