Claude Artifacts to Blog

Artifacts become blog posts built from native Odoo snippets

An artifact is a self-contained HTML page with its own CSS and its own diagrams. Pasted into a blog post it looks right and cannot be edited: the website editor recognises nothing in it. This module takes it apart and puts it back together with the snippets Odoo already knows.

What it maps

  • Headings to s_title with table-of-content anchors
  • Callouts to s_alert, level taken from the marker
  • Figures to s_big_number and column boards
  • Tables into their own scroller, diagrams with their colours kept
  • <details> to s_accordion

What it never does

  • Publish on its own — the blog post is always a draft
  • Let the artifact CSS or scripts reach the page
  • Call a language model: the parser is deterministic
