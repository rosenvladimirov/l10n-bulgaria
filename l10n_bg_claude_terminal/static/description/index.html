Claude Terminal

AI-powered terminal embedded in Odoo chatter, list & kanban views

Overview

Integrates Claude Code CLI directly into Odoo via an embedded terminal panel. Works with a local Docker ttyd instance or an external multi-user terminal server with API key authentication.

Features

  • Chatter panel — Claude button next to Send message / Log note
  • List & Kanban — AI button next to New
  • Live refresh — field flash (blue) and row highlight (green) when Claude modifies records
  • External terminal — switch to multi-user Docker terminal with API key auth
  • Session context — auto-passes model, record ID, database to the terminal

Terminal Modes

Mode Description
Local (default) Connects to ttyd on localhost — no API key needed
External Connects to Docker terminal with Odoo API key auth, per-user workspace

Configuration

  1. Go to Settings → Users → Preferences
  2. Set Claude Terminal URL (e.g. http://localhost:8080)
  3. Optional: enable Use External Terminal and enter your Odoo API Key
  4. Configure Odoo RPC connector (URL, database, protocol)

MCP Server Integration

Works with odoo-claude-mcp Docker stack providing 60+ Odoo tools, memory storage, Gmail, Calendar, Telegram, SSH, Git, and Portainer management — all accessible from Claude Code CLI.
