Integration with ERP.BG fiscal printers for Odoo POS.
The module provides connection to ErpNet.FP server for fiscal receipts.

Configuration
============

To configure this module, you need to:

* Install and configure ErpNet.FP server
* In Odoo go to Settings -> POS -> Fiscal Printers
* Create a new fiscal printer
* Enter the URL of the ErpNet.FP server
* Assign the printer to POS point of sale

Usage
=====

To use this module:

* Open POS interface
* When completing a sale, the system will automatically issue a fiscal receipt
* Fiscal status can be tracked in the order details
* In case of error, the system will attempt to reissue the receipt
