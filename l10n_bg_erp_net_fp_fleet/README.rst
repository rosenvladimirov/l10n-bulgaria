Central control plane for distributed ErpNet.FP proxy instances.

Each shop runs an ``Odoo.ErpNet.FP`` proxy locally to drive its
fiscal printer over USB / TCP. This module collects heartbeats from
all such proxies into a single Odoo backend and lets administrators:

* Generate one-time pairing tokens to enrol new proxies
* Watch ``last_seen`` and computed ``alive`` status
* Trigger remote ``/admin/self-update`` (one-shot ``docker:cli``
  sidecar runs ``compose pull && compose up --force-recreate``)
* View the most-recent log lines without shell access
* Program fiscal-printer VAT rates remotely

The proxy's admin token (which grants ``/admin/*`` access) is
stored Fernet-encrypted at rest with a key kept in
``ir.config_parameter`` (visible only to ``base.group_system``).

This module is designed to run on a dedicated CE Odoo instance
(default: ``iot.mcpworks.net``) — it has no dependency on
``point_of_sale``, ``iot``, ``mrp``, or ``stock`` and the central
registry need not also host the POS that actually uses the printers.

Usage
=====

1. Install ``l10n_bg_erp_net_fp_fleet``.
2. Open *Fleet → Proxies → New*, name the proxy, save.
3. Click *Generate Pairing Token* — a one-hour token is shown.
4. Edit the proxy's ``config.yaml``:

   .. code-block:: yaml

      server:
        registry:
          enabled: true
          url: "https://iot.mcpworks.net"
          pairing_token: "<paste here>"

5. Restart the proxy. It pairs once, persists the long-lived secret
   to ``config.yaml``, and starts heartbeating every 60 seconds.
6. From the form view, use *Self-update* / *View Logs* / *Program VAT*
   to operate the proxy remotely.
