Datecs PM Fiscal Printer (direct)

Direct Python driver — без ErpNet.FP dependency

Pure-Python имплементация на Datecs PM Communication Protocol v2.11.4 за новото поколение Datecs fiscal devices (FP-700 MX и сродни). Покрива back-office (фактуриране, MRP) и POS (retail) сценарии в Odoo 18.

Три топологии

Serial / USB

Локален Odoo на същата машина като устройството. Латентност < 50 ms. Single-shop SME пазар.

TCP през VPN

Cloud Odoo (VPS) + TCP принтер в магазина през OpenVPN/WireGuard. Multi-shop deployment.

Cloud agent

Когато устройството е само serial и магазинът няма VPN. Локален Python IoT agent forward-ва командите.

Архитектурни принципи

  • drivers/ е pure-Python, не импортира odoo — тества се изолирано
  • Транспортите са взаимозаменяеми (един Transport ABC)
  • Frame layer е stateless; sequence number се подава отвън
  • Append-only frame log за Наредба Н-18 compliance
  • Idempotent retry чрез NSale (UNS) per receipt

Не е extension на l10n_bg_erp_net_fp

Двата модула съществуват паралелно. Клиентът избира кой да инсталира според своя hardware:

  • l10n_bg_erp_net_fp — за устройства зад ErpNet.FP HTTP сървър (стар hardware)
  • l10n_bg_fiscal_printer_datecs_pm — директен Python driver (нов hardware)
