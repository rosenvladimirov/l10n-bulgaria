This module generates Intrastat XML report for declaration compliant with
Bulgarian National Revenue Agency (NRA) requirements.

**Table of contents**

.. contents::
   :local:

Features
========

* XML export for Bulgarian Intrastat declarations
* Support for both Arrivals (Пристигания) and Dispatches (Изпращания)
* Automatic validation of required fields
* Compliance with Bulgarian NRA XML schema
* Support for monthly and quarterly reporting periods
* Automatic calculation of totals
* Partner VAT validation
* Product origin country tracking
* Transport mode and Incoterm support
* Region code support

Configuration
=============

Before using this module, you need to configure:

Company Settings
----------------

Go to **Settings > General Settings > Companies**:

* Set the company's Intrastat region code
* Configure default transport mode
* Configure default transaction codes for invoices and refunds
* Set the tax contact person with all required fields:

  * UID and UID Type
  * Street number
  * City and Postal code
  * Phone, mobile, email

Partner Settings
----------------

For each EU partner, ensure:

* Country is set and marked as Intrastat member
* VAT number is correctly filled
* Shipping address is complete (for dispatches)

Product Settings
----------------

For each product:

* Set the Commodity Code (Intrastat code)
* Set the Country of Origin
* Set weight or supplementary units
* Configure supplementary unit amount if applicable

Invoice Settings
----------------

For each invoice/bill:

* Verify Intrastat country is set
* Set transport mode
* Set Incoterm
* Verify transaction codes on invoice lines

Usage
=====

Generate XML Report
-------------------

1. Go to **Accounting > Reporting > Intrastat**
2. Select the reporting period (month or quarter)
3. Choose report type:

   * **Arrival** (Пристигане) - for purchases from EU
   * **Dispatch** (Изпращане) - for sales to EU

4. Click on **XML** button
5. The system will validate all required data
6. Download the generated XML file
7. Upload the file to the NRA portal

Report Validation
-----------------

The module performs automatic validation:

* Missing H.S. codes
* Missing VAT numbers (for dispatches)
* Missing country of origin
* Missing weight or supplementary units
* Missing transaction codes
* Missing transport modes
* Missing Incoterms
* Invalid date ranges

If validation fails, the system will show an error message with specific
missing data, allowing you to correct it before generating the report.
