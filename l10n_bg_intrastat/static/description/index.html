Bulgarian Intrastat XML Export

Generate Intrastat XML declarations compliant with Bulgarian National Revenue Agency (NRA) requirements

This module extends the standard Odoo Intrastat reporting to generate XML files specifically formatted for the Bulgarian National Revenue Agency (NRA). It supports both monthly and quarterly reporting periods for Arrivals (Пристигания) and Dispatches (Изпращания).

Key Features

XML Export

Generate NRA-compliant XML files with automatic validation of all required fields

Arrivals & Dispatches

Full support for both Intrastat Arrivals (imports) and Dispatches (exports)

Validation

Comprehensive validation of commodity codes, VAT numbers, transport modes, and more

Flexible Reporting Periods

Support for both monthly and quarterly declaration periods

Automatic Calculations

Automatic calculation of total mass, amounts, and statistical values

Country of Origin

Track and report product country of origin for compliance

Transport & Incoterms

Complete support for transport modes and Incoterm codes

Configuration Process

Step 1

Configure company Intrastat region, transport mode, and transaction codes

Step 2

Set up tax contact person with all required details (UID, address, contacts)

Step 3

Ensure partners have valid VAT numbers and Intrastat-enabled countries

Step 4

Configure products with commodity codes, origin country, and weights

How to Use

  1. Navigate to Accounting → Reporting → Intrastat
  2. Select the reporting period (month or quarter)
  3. Choose report type: Arrival (purchases from EU) or Dispatch (sales to EU)
  4. Click the XML button to generate the declaration
  5. Review any validation errors and correct the data if needed
  6. Download the generated XML file
  7. Upload the XML file to the NRA portal

Comprehensive Data Validation

The module performs thorough validation before generating XML files

Commodity Codes
  • Missing H.S. codes
  • Expired commodity codes
  • Invalid code dates
VAT Numbers
  • Missing VAT numbers (dispatches)
  • Invalid VAT format
  • Partner validation
Product Data
  • Missing product weights
  • Missing supplementary units
  • Missing origin country
Transport & Incoterms
  • Missing transport modes
  • Missing Incoterm codes
  • Invalid transaction codes
