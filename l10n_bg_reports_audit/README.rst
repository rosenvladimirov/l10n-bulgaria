**Reporting for Bulgarian Localization – Technical Module**

This technical module is developed to support the generation of reports and files required for submission to the National Revenue Agency (NAP) in Bulgaria. It is not intended for standalone use, but operates in coordination with additional EE or CE modules, which are responsible for producing the relevant print forms and declaration files.

.. contents::
   :local:

Description
----------
This module extends the Odoo Accounting localization for Bulgaria by providing:

* VAT Report-Declaration
* VAT sale reports
* VAT purchase reports
* VIES reports
* Account tags management
* Company configuration extensions

Installation
------------
To install this module, you need to:

* Just install it with no specific requirements

Configuration
-------------
To configure this module, you need to:

* Go to Accounting -> Configuration -> Settings
* Set up Bulgarian specific options
* Configure company information

Usage
-----
To use this module, you need to:

* Go to Accounting menu
* Select Reports
* Choose desired report type
