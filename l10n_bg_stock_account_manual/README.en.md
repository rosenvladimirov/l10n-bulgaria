# Bulgaria - Stock Auto Accounting - Manual

In-app user guide for **l10n_bg_stock_account**, shown through the
`markdown_viewer_locale` framework.

Open it from the Markdown Viewer on **Receipts/Deliveries** (`stock.picking`),
**Product Categories** (`product.category`) or the generated **Journal Entries**
(`account.move`). Available in Bulgarian and English (auto-selected by user language).

Content: what the module does, per-category account configuration, the journal
entries generated on receipts/deliveries/scrap/inventory adjustments, the
`l10n_bg_account_move_ids` viewer, interaction with `l10n_bg_stock_price_diff`,
and common mistakes.
