# Markdown Viewer (Locale-aware)

> Рендира локализирани Markdown файлове (README.bg.md vs README.en.md /
> README.md) спрямо езика на потребителя — ползва се за показване на
> правилната per-module документация вътре в Odoo.

**Модул:** `markdown_viewer_locale` | **Версия:** 18.0.3.0.8 | **Лиценз:** LGPL-3 | **Категория:** Localization

## Описание

Всеки локализационен модул доставя `README.en.md` + `README.bg.md` (и
някои `README.md`). Този инструмент избира и рендира варианта,
съответстващ на езика на логнатия потребител, така че български
потребител вижда българската документация, а английски — английската
— вътре в Odoo UI, не само на GitHub.

## Какво прави

Избира locale-съответстващия Markdown файл (`*.bg.md` за `bg_BG`,
fallback към `*.en.md` / `*.md`) и го рендира.

## Бележка за статуса (2026-04-30)

`FormController` JS patch, който отваряше viewer-а в popup, причини
breakage и беше **изключен за изолация**. Без бутона popup-ът не се
auto-отваря; самата logic за избор по locale е интактна. Re-enable
изисква възстановяване на FormController patch-а (виж коментарите в
`static/`).
