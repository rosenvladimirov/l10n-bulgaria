## Инсталация

```bash
# Добавете пътя на репозиторията в Odoo addons_path,
# след това инсталирайте през UI Apps → търсене 'markdown_viewer_locale' или през CLI:
odoo -i markdown_viewer_locale -d <вашата_база> --stop-after-init
```
