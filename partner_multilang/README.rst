This module extends the functionality of multilingual names to support automatic transliteration (ISO 9, ΕΛΟΤ 743) and provides easy field translations for partners, companies, and addresses.

Use Cases / Context
===================

Legal Requirements
------------------

Countries using Cyrillic letters (Bulgaria, Russia, Serbia, Macedonia, Ukraine, Belarus) have legal requirements for transliteration to Latin in official documents.

Sorting Problems
----------------

Non-Latin scripts create sorting issues in list and kanban views. For example, Cyrillic "Г" and Latin "G" are positioned differently, leading to confusion when navigating through records.

Technical Limitations
---------------------

In Odoo versions before 16.0, ``display_name`` was not translatable. Version 16.0 introduced computed fields with multi-language support, but only for reports, not for the interface.

Installation
============

To install this module, you need to:

1. Install the required Python dependencies:

   * ``transliterate`` - for language-specific transliteration
   * ``unidecode`` - for universal Unicode to ASCII conversion
   * ``lingua`` - for accurate language detection

2. Install the module through Odoo's Apps menu

Configuration
=============

To configure this module, you need to:

1. Go to **Settings → Translations → Languages**
2. Select the language you want to enable transliteration for (e.g., Bulgarian, Russian, Serbian)
3. Check the **Transliterate** checkbox
4. Save the changes

Supported Languages
-------------------

The module automatically detects and transliterates the following languages:

* Bulgarian (bg) - ISO 9 standard
* Russian (ru) - ISO 9 standard
* Serbian (sr) - Cyrillic to Latin
* Macedonian (mk) - Cyrillic to Latin
* Ukrainian (uk) - Cyrillic to Latin
* Belarusian (be) - Cyrillic to Latin

Transliterated Fields
---------------------

The following fields are automatically transliterated:

* **Partners**: name, street, street2, city, function, company_name, commercial_company_name
* **Companies**: name, street, street2, city
* **Country States**: name

Usage
=====

Basic Usage
-----------

1. Enable transliteration for desired languages in Settings → Translations → Languages
2. Create or edit a partner in a language with transliteration enabled
3. Enter the name and address in the original script (e.g., Cyrillic)
4. The module automatically creates a transliterated version in English

Multi-Language Search
---------------------

Search works across all language translations:

* Search for "Росен" → finds the partner
* Search for "Rosen" → finds the same partner
* The search uses JSONB translations for all active languages

Automatic Sorting
-----------------

List and Kanban views automatically sort by the current user's language:

* Bulgarian users see: "Анна, Борис, Георги"
* English users see: "Anna, Boris, Georgi" (transliterated and properly sorted)

Extend to Custom Models
------------------------

To add transliteration support to your custom models::

    from odoo import api, fields, models

    class CustomModel(models.Model):
        _inherit = ['your.model', 'res.transliterate.mixin']
        _name = "your.model"

        name = fields.Char(translate=True)
        description = fields.Char(translate=True)

        @api.model
        def _get_transliterate_fields(self):
            res = super()._get_transliterate_fields()
            return res + ['name', 'description']

* Integration with product names and sale orders
