To configure this module, you need to:

1. Go to **Settings → Translations → Languages**
2. Select the language you want to enable transliteration for
3. Check the **Transliterate** checkbox
4. Save the changes

Supported languages for automatic transliteration:
- Bulgarian (bg) - ISO 9 standard
- Russian (ru) - ISO 9 standard
- Serbian (sr) - Cyrillic to Latin
- Macedonian (mk) - Cyrillic to Latin
- Ukrainian (uk) - Cyrillic to Latin
- Belarusian (be) - Cyrillic to Latin

The module automatically detects the input language and applies the appropriate transliteration.
