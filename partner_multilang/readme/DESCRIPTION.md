This module extends the functionality of multilingual names to support automatic transliteration (ISO 9, ΕΛΟΤ 743) and provides easy field translations for partners, companies, and addresses.

Key features:

- Automatic language detection and transliteration
- Multi-language search across all translations
- Smart sorting by user's language
- Support for Cyrillic languages (Bulgarian, Russian, Serbian, Macedonian, Ukrainian, Belarusian)
- Easy extension to custom models
