Partner Multilang

Support for multilingual names with transliteration - ISO9, ΕΛΟΤ 743, and easy field translations for partners

This module extends the functionality of multilingual names to support transliterate ISO9, ΕΛΟΤ 743 and to allow you to add easy field with translations on partner.

Use Cases / Context

This module is technical solution for support of transliterate.

  • The countries using cyrillic letters have legal requirements for transliteration to latin.
  • Greek and many other languages with non-latin alphabets.

Installation

To install this module, you just need to install it from the Apps menu - no additional setup required.

Configuration

  • Add field name display_name_xx where xx is language code.
  • Example: display_name_bg.
  • Add transliterate engine for current language.

Usage

  • Create additional module and add field name display_name_xx.
  • Create transliterate library.
  • Inherit the fields and library in res.partner.
