1. Open a product that can be sold and click **Translate Page**.
2. Check the website and the languages. By default, the languages of the
   product's website are proposed without its default language.
3. Narrow the list with the element switches or with **Only Untranslated**,
   then click **Reload Terms**.
4. Fill in the **Translation** column. An empty translation means the source
   is shown on the website; clearing an existing translation removes it.
5. Click **Save**. Only the changed lines are written, and the list is
   reloaded with the new state.
